# Образцы выгрузки сторонней программы

Три живых файла, на которых написан и сверен пакет `ru.services.importing`. Лежали в `docs/samples/`
(каталог `docs/` не в git) — перенесены сюда 2026-08-29, чтобы образцы были на тест-классpath и их
можно было читать из тестов, а не только глазами.

| Файл | Разрез (`CutKind`) | Чем важен |
|---|---|---|
| `911.html` | `GROUP` | источник истины по позиции занятия (И-1); на нём измерено «14 занятий из 197 теряет групповой разрез» (И-21) |
| `ГоряиновР.И..html` | `EDUCATOR` | атрибуция «кто ведёт» — без него строка не разрешается в `Assignment` (И-14, И-23) |
| `252-3.html` | `AUDITORIUM` | позиция из него не читается (И-1), но `OrgUnitHints` берёт отсюда кафедру-владельца комнаты (И-24) |

Спецификация формата и реестр решений И-* — в `docs/IMPORT_FORMAT.md`.

⚠️ Файлы содержат реальные ФИО преподавателей и номера групп. Если каталог `backend/` коммитится,
это попадёт в git — решать до `git add`.

Тесты пакета сейчас строят HTML-фикстуры строками в коде; эти файлы ими не читаются.
